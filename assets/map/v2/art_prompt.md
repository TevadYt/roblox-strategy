# Art prompt for the 140-territory layout

Attach `map_structure.png` from this folder (the version **without** numbers) as the reference image, then use:

```
Repaint this exact map as a hand-painted fantasy strategy board-game map, top-down view, rich painted detail with soft warm lighting, deep blue ocean with turquoise shallows along the coast.
Keep every territory shape and border, the coastline, islands, rivers, dashed sea routes and golden continent outlines exactly as in the reference. Do not add, merge or split territories.
Borders: thin, faint, semi-transparent grey. Golden outlines only where the reference has them.
Paint each territory as its reference colour: grey-brown = rocky ground with 1 to 3 small peaks (never a full mountain range) plus a small stone quarry with cut blocks or a timber-framed mine entrance where the reference shows one; tan = plateau with flat mesas; light green = plains; mid green = valley; sand = desert dunes; dark green = forest groves; pale teal = lake. Small ponds where the reference has blue ovals.
Keep every feature small and inside its own territory, never crossing a border, with open ground at each territory's center.
No snow, no text, no numbers, no labels.
```

Colour key used in the reference: brown-grey = mountain, tan = plateau, light green = plains,
mid green = valley, sand = desert, dark green = forest, pale teal = lake. The grey terraced oval is
a quarry, the dark arch is a mine.
