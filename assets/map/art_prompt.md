# Stage 2 prompt (art model)

Attach `map_structure.png` (the version **without** numbers) as the reference image, then use:

```
Repaint this exact map as a hand-painted fantasy strategy board-game map, top-down view, soft watercolor textures, warm natural colors, deep blue ocean around the land. Keep every territory shape, border, river, coastline and golden continent outline exactly as in the reference. Borders: thin semi-transparent light grey. Inside each territory paint only small terrain motifs matching its color (small mountain, small grove, small pond, small dunes), never crossing borders, with open ground in the center. No snow, no text, no labels.
```

Optional addition, if the model drops the dashed sea routes to the islands:

```
Keep the thin dashed white sea-route lines between the islands and the coast.
```

Colour key used in the reference: brown-grey = mountain, tan = plateau, light green = plains,
mid green = valley, sand = desert, dark green = forest, pale teal = lake.
